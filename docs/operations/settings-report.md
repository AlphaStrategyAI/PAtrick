# T17 设置命令与偏好

这一阶段的本地实现已将草稿、设备、当前身份、权限作用域、资源基线和有效期纳入验证证明。应用请求必须逐项匹配，并取得绑定本次验证和资料域的 T03 控制回执。相同请求读取已记载的回执；当目标仍在应用、复查或结果未知时，服务拒绝竞争变更。复查失败保留已应用版本和逐项效果，不根据复查失败撤销实际应用，也不续办业务。

设置和系统按相同 change ID 读取同一回执。偏好字段有限制，按账户保存；语言和减少动效即时用于呈现，账户保存失败显示未同步。已登记的 Vault 确认复用 T06；飞书启用复用 T10 的精确测试和连接证据；停用锁住旧渠道 epoch，只有具备发送许可的在途答复进入排空。UI 对尚未注册的操作显示本安装暂不可用。

本地测试覆盖改草稿/设备/有效期、部分应用和复查失败、并发目标拒绝、正式 T03 回执接通隔离 Vault、偏好 CAS、多账户隔离、六组导航及浏览器语言保存失败。已登记 Vault 可走三步确认向导；真实 Vault 换位、飞书凭据配置和配对测试向导、真实飞书排空的终态、主机修复工作流仍需继续。未知应用结果当前只保留回执并阻挡重复执行，自动复查和可逆项的拥有权回滚还待补齐。

## 独立复审后的回归

- 飞书回答的发送顺序号和原意图在联系 Hub 前提交。停用的栅栏因此会等待尚未收到响应的许可；只接纳与该许可、连接代次和排空范围相符的读回。测试让 Hub 确实收到请求后暂扣响应，确认此时状态仍是「排空中」。
- 启用与停用在渠道实际写入的 SQLite 事务内重新核对原会话、确认回执、权限和冻结的渠道身份、证据及版本。使用数据库第二条连接撤销权限或重新绑定后，配置版本不变也不会接受旧回执。
- Vault 检查要求获准目录仍存在、身份一致且可读写。最终事务重查当前会话、资料域授权、确认回执有效期、配置和设备映射，并在 CAS 前重新核对目录；确定没有写入的情形留下受阻回执，不占用未知结果的栅栏。
- 偏好改动携带当前页面读回的账户及授权代次。另一标签页换登录后，旧页面对相同偏好版本的请求也不会写到新账户。
- 验证和准备确认各自按命令请求键保存首次完整快照，同键同参数重放原结果，改参数返回冲突。并发的相同验证只登记一份证明。
