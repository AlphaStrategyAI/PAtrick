# T15 决策、工作与咨询验收记录

本轮验收使用 Chromium 虚拟验证器走 T03 WebAuthn，连接真实 Hono 路由和临时 SQLite。Hub 使用本机持久测试端口；咨询的终态由真实 T11 版本 CAS 写入。办公室、公司、个人库和付费模型均不在此次夹具范围内。

- **同一项工作。** 从待决定进入 `W-017`，退出咨询后返回原卡。咨询与普通消息中的“同意”没有产生决定回执或续办条目。显式提交冻结 A 选项时，浏览器故意丢失首次 HTTP 响应，以原请求 ID 和原正文重试，最终取得一次已核验回答。T10 的正常领取接口随后仅为 `W-017` 领取一次补证授权；工作详情显示同一 ID 和核验历史。
- **咨询与语言。** 咨询尚未完成时切换英文，页面读回同一请求；收到的原文保持不变。切回中文只改变呈现；没有再发咨询。
- **小屏和失效卡。** 自定义决定与咨询独立保存；Escape 关闭对话后焦点回到入口。原问题被替换后原稿仍可见，新问题没有预选或自动带入原稿。关联工作需要明确勾选，新的自定义决定按原话写入。
- **撤权和迟到响应。** 两个标签页先订阅，再断开并撤销真实会话。重连后两个页面均收到未登录证据、隐藏旧范围；释放旧响应后没有重新显示，私有草稿已清理。
- **冻结选项读取。** 决策接口仅返回该资料域获准的冻结公示选项及绑定字段；同一账户在另一资料域的读取授权不适用。原始规则和原始选项 JSON 不输出。

隔离快照验证：`npm exec -- playwright test --config tests/e2e/T15.config.ts` 四项通过；T10/T11/T13/T01 的 35 项集成与合同测试通过；类型检查、lint 和 Web 生产构建通过。故意丢包用例中 Vite 记录一次 `socket hang up`，随后的同键重放通过。

工作页使用独立的工作控制版本。确认暂停、恢复或已配置的停止请求后，页面只显示这次命令对应的精确回执。同一请求键重放不再次变更；未配置停止监督器的部署不会显示停止按钮。即使已提交停止，进程树和外部效果未同时核验时也保持“正在核对”而非“已停止”。停止监督器的实机接入和现场证据留给部署任务。工作冷启动时，受权但尚未投影的详情返回可重试状态，未知或越域的对象仍拒绝访问。

未进行真实 Hub、付费后端或跨入口生产联调。
