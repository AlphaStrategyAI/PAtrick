# T17 飞书交互设置本地验收

从「设置 → 交互 → 飞书机器人」读取当前账户和资料域的连接、本人目的地及报告时间。向导依次展示应用凭据、本人单聊配对和测试预览。配对候选出现后，用户确认平台身份及资料域；预览引用当前绑定的 App ID、目的地和固定样例，不包含业务资料。刷新页面沿用服务保存的测试回执。

- 凭据入口须由受信 HTTPS 来源、Web 属主和明确接入的飞书凭据提供器共同开启。默认服务没有该提供器，不显示密钥输入，也不会使用会话凭据目录接收 App Secret。首次暂存只产生 probe，真实租户和权限未核验前不能生成配对码。现有连接不能通过此入口替换凭据或重新配对。
- 配对码只在受信 HTTPS 的属主专用回执中显示一次，五分钟过期。业务数据库只保存散列；一般状态查询和命令账本不返回明文配对码。换发后，原配对回执仍按原资料域显示为已过期；确认请求只能按原配对 ID 重放。
- 当前安装没有受监督的飞书传输。可读已绑定探针的预览，发送入口拒绝请求且不改变测试状态，不产生平台消息 ID、回传证据或待启用状态。待启用和停用操作继续使用独立的 Settings 验证、确认及复查回执。
- 原生验收仍需 T23 的可信 HTTPS／系统凭据提供器，以及运行中的 T10 飞书长连接、企业自建应用、真实单聊回调及双向测试证据。凭据轮换也仍需准确的设置授权与停用排空切换流程。

## 应用凭据放在哪里

原生准入与应用设置读取同一份应用凭据，环境变量优先，其次是本机文件。文件默认在 `~/.patrick/secrets/feishu.env`，也可以用 `PATRICK_FEISHU_CREDENTIALS_FILE` 指向别处。文件只放两行，权限 `0600`，留在仓库之外：

```
FEISHU_APP_ID=cli_xxxxxxxxxxxxx
FEISHU_APP_SECRET=xxxxxxxxxxxxxxxx
```

`LARK_APP_ID` 与 `LARK_APP_SECRET` 是同义的别名。凭据只进入子进程的环境，不写进命令、观察记录或提交；准入探针的观察只记录退出码，不记录密钥本身。

本地证据来自隔离 SQLite、临时凭据存储、原生传输缺失分支以及浏览器回归。测试中的候选身份由测试夹具写入，只用于核对界面和状态边界，未连接飞书或发送任何外部消息。
