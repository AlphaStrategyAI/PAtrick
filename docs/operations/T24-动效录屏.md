# 运行标识动效录屏

[播放测试录屏](evidence/T24-service-logo-playback.webm)记录了已登录的合成工作台和等待决定的样例。视频长 26.36 秒，画面为 800 × 554、25 帧/秒。前段等待服务状态确认，显示 `Running` 后，左上角标识开始循环，右侧决定卡保持等待。画面与状态来自隔离的本地测试服务，使用测试数据。

本次运行的源代码对应提交 `7f5ce34eb30478903c55f78bfe54fb83009a32cf`。Playwright 使用 Chromium headless shell 156.0.8078.4，原始视口为 1440 × 1000，DPR 为 1，系统动效偏好为 `no-preference`。浏览器录屏缩放为上述视频尺寸。测试监听到连续两个 `animationiteration` 事件，经过时间分别为 4.8 和 9.6 秒，间隔为 4.8 秒。两个周期中状态文字的 DOM 更新次数为零。随后测试切换中文并核对状态仍可见。

复现入口如下，运行需要仓库锁定的 Node、依赖和 Playwright Chromium。

```sh
PLAYWRIGHT_JSON_OUTPUT_FILE=/private/tmp/patrick-t24-playback.json \
  npm exec -- playwright test --config tests/e2e/T24.config.ts \
  --grep 'the 4.8s orbit repeats' --reporter=line,json
```

该测试配置启用视频，测试输出目录的 `video.webm` 可复核可见播放。计时数据保存在 JSON 报告中名为 `playback` 的附件，其 `body` 以 base64 编码。减少动效、隐藏页面、过期状态和断联的静态行为由同一测试文件覆盖。录屏证明本地受控环境中这一次实际播放，完整界面视觉与原生读屏验收仍需各自的证据。
